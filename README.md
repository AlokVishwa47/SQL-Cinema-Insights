# 🎬 Cinema Data Intelligence (SQL Case Study)

## 📌 Project Overview
This project demonstrates advanced SQL techniques to analyze movie performance. The goal was to connect fragmented data across multiple tables to provide a clear picture of business success.

## 🛠️ Tech Stack & Skills
- **SQL (Joins):** Connecting Movie metadata with Sales records.
- **Data Filtering:** Using `WHERE` and `IS NULL` for data integrity.
- **Business Metrics:** Calculating Total Revenue using SQL Expressions.

## 📊 Key Insights Extracted
- Identified top-performing genres by merging `Movies` and `BoxOffice` tables.
- Detected movies with missing ratings to highlight data gaps.
- Calculated the ratio of Domestic vs. International sales for global market analysis.

- `analysis.sql`: Contains the primary queries used for the case study.
